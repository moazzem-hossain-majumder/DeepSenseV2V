# Scenario 39 trajectory contributions

Within Scenario 39, sequences 50 and 51 together accounted for 77.5% of the net 2.747-point difference between the pooled and transfer visual gains over GPS. Each sequence supplied 187 of the 3,179 validation windows. In sequence 50 the transfer visual model tied geometry on average. In sequence 51 it fell 11.41 percentage points below geometry. The pooled-minus-transfer contrast was +4.343 points within block 39:8 and -0.178 within block 39:9. With only two observed validation blocks, a scenario-wide explanation for the visual loss remains uncertain.

Each contribution is the sum of paired window differences divided by the full scenario window count. Values average seeds 42, 7 and 13. The two sequences were identified retrospectively. See evidence.json for all 17 sequences and both blocks.
