```python

# Active refinement: boost high-power alternatives within candidate subset
```

**Forensic Finding:**  
Rather than evaluating a neural network that fuses GPS, RGB, and kinematics, the code simply copies the baseline geometry logits (`geo_logits.copy()`) and adds an ad-hoc, synthetic cosine array `0.35 * cos(...)` to the top 20 candidate beams!
